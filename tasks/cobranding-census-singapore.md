## The definition (identical to the prior runs - do not drift)

A row is a brand x character IP collaboration campaign running in Singapore with any activity in 2024, 2025, or 2026 year-to-date. F&B-led but not F&B-only: retail, convenience, telco, banking, mall, and loyalty campaigns count when a character IP fronts a consumer campaign.

**Ownership test per IP (the bucket call):**
- portfolio = owned by a corporation, estate, platform, or media franchise (or majority stake)
- independent = creator-owned. Agency-managed but creator-owned = independent (the 咖波 precedent)
- unclear = genuinely unresolvable after digging - use sparingly, record what was checked

**Pinned edge cases (carried forward):**
- Miffy = portfolio (estate + other IP); Snoopy = portfolio (Sony stake)
- Government-owned mascots = EXCLUDED (the Kumamon rule) - note SG has state-adjacent mascots (e.g. campaign mascots of statutory boards); apply the rule and record exclusions
- Platform-owned characters (LINE Friends class) = portfolio
- Label-captive indies: indie by ownership but exclusively channelled through a toy label = REP no (the LuLu the Piggy / Toyzeroplus precedent - expect this class in SG's art-toy retail scene)
- The per-IP ownership test even when one creator sits on both sides of the line (the Molly Factory precedent)
- Self-presentation is not ownership: artist-side keywords are a detector of creator-voiced coverage, not of independence - the ownership test decides every bucket

**REPRESENTABLE sub-tag** on independent rows only: yes / no / unclear.

## The Singapore-specific key calls

1. **English-dominant sources - but sweep both query classes from the start.** SG press is reachable in EN (Straits Times lifestyle, Mothership, TimeOut SG, marketing trade press, mall socials). Brand-side terms AND artist-side terms (illustrator, local artist, Singapore artist/illustrator, homegrown artist, creator collab) run together - the four-mechanisms taxonomy predicts SG behaves either like Taiwan (press names creators - small correction) or like Japan (artist-named campaigns invisible to brand queries - channel mechanism). Record which mechanism SG exhibits in the verdict; it is a finding either way.
2. **The regional-HQ trap.** SG hosts SEA regional HQs, so campaigns get ANNOUNCED from Singapore that never activate there. A row requires evidenced SG activation: SG stores, SG-market announcement, SG mall presence, .sg commerce. Regional announcements without SG activation are rejected and listed. (The MY franchise-local rule, inverted for an HQ market.)
3. **Mall and loyalty concentration.** CapitaLand malls (Plaza Singapura, ION), Jewel, Takashimaya, and the CVS/loyalty programmes (7-Eleven SG, FairPrice) run character campaigns at density - each campaign one row per the standard rule, anti-inflation merges for multi-mall single campaigns (one campaign across several CapitaLand malls = one row, venues noted).
4. **The art-toy retail scene** (POP MART SG, ActionCity, local designer-toy shops): licensor's own retail excluded per the pinned rule; venue-hosted properties ARE rows per the Taiwan-v2 row 126 precedent.
