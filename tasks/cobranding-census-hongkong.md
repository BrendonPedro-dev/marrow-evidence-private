## The definition (identical - do not drift)

A row is a brand x character IP collaboration campaign running in Hong Kong with any activity in 2024, 2025, or 2026 year-to-date. F&B-led but not F&B-only: retail, convenience, telco, banking, mall, transit, and loyalty campaigns count when a character IP fronts a consumer campaign.

**Ownership test per IP:** portfolio = corporation/estate/platform/franchise-owned (or majority stake); independent = creator-owned (agency-managed but creator-owned = independent, the 咖波 precedent); unclear = genuinely unresolvable after digging, used sparingly with the search trail recorded.

**Pinned edge cases (carried forward):**
- Miffy = portfolio; Snoopy = portfolio; government-owned mascots = EXCLUDED (Kumamon rule)
- Platform-owned characters = portfolio
- Label-captive indies = REP no (the LuLu the Piggy / Toyzeroplus precedent - and NOTE: HK is Toyzeroplus's home market and the art-toy label capital; expect this class to be the market's defining REP call. Dig past every label to the creator: label-OWNED character = portfolio; creator-owned but exclusively label-channelled = indie, REP no; creator-owned and label-distributed non-exclusively = indie, REP per evidence)
- Per-IP ownership test even for one creator on both sides (Molly Factory precedent)
- Self-presentation is not ownership - the test decides, not the keyword

**REPRESENTABLE sub-tag** on independent rows: yes / no / unclear.

## The Hong Kong-specific key calls

1. **The art-toy label capital.** HK's character economy runs dense with designer-toy labels (Toyzero+, How2work, Kennyswork legacy, ToyQube-class) and label-affiliated creators. The market's indie number will be decided by careful label-vs-creator ownership calls - record the evidence per row, and expect the REP=no share of indies to be the highest in the series. That itself is a finding: indie-by-ownership but captive-by-channel is the HK pattern to test.
2. **Bilingual sources, zh-HK first-class.** Sweep zh (traditional, Cantonese-register press: HK01, U Lifestyle, 港生活, am730 lifestyle, mall and brand socials) AND EN (SCMP lifestyle, Time Out HK, Localiiz, Marketing-Interactive). Artist-side terms both languages: 插畫家, 本地插畫家, 本地藝術家, 創作人, illustrator, local artist, homegrown. Record which of the four mechanisms HK exhibits.
3. **Mall + transit concentration.** K11, Langham Place, Times Square, Harbour City, LCX run character campaigns at high density; MTR runs character tie-ins at network scale. Standard one-campaign-one-row with anti-inflation merges (one campaign across several venues of one operator = one row, venues noted).
4. **The cross-border trap.** HK campaigns and Greater-Bay/mainland campaigns get announced together. A row requires evidenced HK activation (HK venues, HK press, .hk commerce) - mainland-only activations announced via HK media are rejected and listed. (The SG regional-HQ rule, GBA edition.)
