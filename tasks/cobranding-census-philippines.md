## The definition (identical - do not drift)

A row is a brand x character IP collaboration campaign running in the Philippines with any activity in 2024, 2025, or 2026 year-to-date. F&B-led but not F&B-only: retail, convenience, telco, banking, mall, and loyalty campaigns count when a character IP fronts a consumer campaign.

**Ownership test per IP:** portfolio = corporation/estate/platform/franchise-owned (or majority stake); independent = creator-owned (agency-managed but creator-owned = independent, the 咖波 precedent); unclear = genuinely unresolvable after digging, used sparingly with the search trail recorded.

**Pinned edge cases (carried forward):**
- Miffy = portfolio; Snoopy = portfolio; government-owned mascots = EXCLUDED (Kumamon rule)
- Platform-owned characters = portfolio
- OWN-MASCOT exclusion, expect it to bite hard here: Philippine brands run beloved proprietary mascots (Jollibee and his friends being the canonical case - Jollibee x anything where Jollibee IS the brand's mascot is NOT a row; a third-party character licensed INTO a Jollibee campaign IS). Record the exclusions - the excluded-mascot list will itself be long and is worth naming.
- Label-captive indies = REP no (the Toyzeroplus precedent)
- Per-IP ownership test even for one creator on both sides (Molly Factory precedent)
- Self-presentation is not ownership

**REPRESENTABLE sub-tag** on independent rows: yes / no / unclear.

1. **English-dominant press with a naming question.** PH marketing/lifestyle press runs largely in English (Spot.ph, Rappler lifestyle, Inquirer lifestyle, When In Manila, adobo magazine for the trade) - the taxonomy predicts PH behaves either like Taiwan (press names local creators - small artist-side delta) or like Thailand (brand PR erases them). Sweep both keyword classes and record which mechanism PH exhibits. Artist-side terms: EN (illustrator, local artist, Filipino artist/illustrator, komiks creator) + Tagalog where productive (ilustrador, artista - flag translation confidence on any Tagalog-source call).
2. **Mall-operator density.** SM Supermalls, Ayala Malls, Robinsons, Megaworld run character events at national chain scale - one campaign across several branches of one operator = one row, venues noted (the anti-inflation merge). 3. **The komiks/webcomic creator scene.** PH has a distinct komiks tradition and an active webcomic/illustrator community (the Tarantadong Kalbo class of creator). Platform-hosted webcomic characters: the artist owns unless the platform demonstrably does (the Korea webtoon rule). This scene is where PH's addressable-indie count will be won or lost.
