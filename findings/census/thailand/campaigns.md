# Thailand co-branding census - campaign log

This is a growing, curl-verified table of identifiable brand-x-IP **co-branding** campaigns in the Thailand market, 2024-01-01 to run date.
Scope is co-branding only - a brand pairing with a character/illustration/toy IP for products, drinks, food, events, pop-ups or stores.
F&B-led but not F&B-only: retail, convenience, telco, banking, and mall campaigns count when a character IP fronts a consumer campaign.
Excluded: plain licensed merchandise at retail, KOL/celebrity endorsements, and brand-x-brand tie-ins with no character IP.
**Status at 2026-07-29: 43 curl-verified rows (12x 2024, 20x 2025, 11x 2026YTD).** This is the seed pass. It was built off one vein (Brand Buffet, the Thai marketing trade title) and is deliberately labelled incomplete: the sticker-native indie creator scene that the task flags as the heart of the Thai indie bucket has NOT yet been mined, and the indie count below (4 rows) should be read as an under-sweep, not as a finding. See "Owed sweeps" at the foot of this header.
This is the THAILAND run in a region-by-region series (Taiwan v2: 129 rows at `findings/census/taiwan-v2/campaigns.md`; Japan: 131 rows at `findings/census/japan/campaigns.md`; Korea: 135 rows at `findings/census/korea/campaigns.md`; Malaysia: 103 rows at `findings/census/malaysia/campaigns.md`); identical definition and rules so all markets compare row-for-row.

**Method (sample census, not exhaustive):** Thai-native keyword sweep of the Thai marketing trade press, run against site search rather than English web search, because an EN-only sweep returns almost nothing for this market.
Keywords swept so far, all in Thai unless noted: คอลแลบ (collab), คาแรกเตอร์ / คาแรคเตอร์ (character, both common spellings - they return different result sets), อาร์ตทอย (art toy), ลิขสิทธิ์ (licence), มาสคอต (mascot), plus EN-transliterated entity names (Sanrio, Butterbear, Pop Mart, Hello Kitty, collaboration).
Every row below was confirmed by `curl` against the live article URL, returning HTTP 200 with a machine-readable `datePublished` in the page JSON-LD; the date column is taken from that field unless a campaign window is stated in the body.
Phantom (unverifiable) entries are the known failure class and are kept out.

**Counting rules applied to the Thai promo landscape (so the row count is not inflated):**
- **One campaign, one row.** Osotspa's Butterbear program ran across two of its brands (Calpis Lacto and Babi Mild) and got two trade articles; it is counted once, with the second article named in Notes. K PLUS's app-theme launch fronted four separate IPs in one campaign and is likewise one row.
- **The IP owner's own retail is NOT a row.** POP MART Thailand store openings, concept-store launches and landmark-store launches are the licensor selling its own goods, not a brand x IP collaboration. A POP MART property hosted BY a third-party venue (EMSPHERE, Siam Center, ICONSIAM) IS a row, on the Taiwan-v2 row 126 venue precedent.
- **A brand's OWN mascot is NOT a row.** Barbecue Plaza's Gon, Thaitheparos's Je Chilly, Cafe Amazon's Baby Zonzon, Thai Airways' Junior Sky Explorers, Starbucks' Bearista and blueplus+'s Nonplus are all in-house mascots and are excluded. The same mascot licensed OUT to a third-party brand IS a row (the Butterbear class - see the ownership note below).
- **Celebrity and personality collabs are NOT rows.** TWINEHIDE x NANAKE555 (a TV host's personal label) and OREO x BTS (a music act, as distinct from its TinyTAN character IP) are excluded - no character IP.
- **Character-goods retail concepts are NOT rows.** Siam Center's Mappy is a multi-IP character-goods concept store, i.e. a tenant, not a brand pairing with one character IP.
- **Plain licensed merchandise at retail is NOT a row**; a retailer-RUN licensed collection or redemption program (CJ MORE x Powerpuff Girls, McDonald's blind box) is.

**YEAR tag** is by campaign start/run date: `2024` = 2024-01-01..2024-12-31, `2025` = 2025-01-01..2025-12-31, `2026YTD` = 2026-01-01..run date.

**IP class** = PORTFOLIO (owned/controlled by a major licensor, studio, media/platform conglomerate, or estate that manages OTHER IP) / INDEPENDENT (living-creator- or small-studio-owned, no conglomerate parent; agency-managed but creator-owned still counts - the Capoo precedent) / UNCLEAR (state why).

**Pinned edge cases (identical to Taiwan-v2/Japan/Korea/Malaysia runs):** Miffy/Mercis BV = PORTFOLIO (estate); Snoopy/Peanuts = PORTFOLIO (Sony controlling stake); Sanrio / San-X / Pokemon-Nintendo / Disney-Marvel / Warner Bros / KAKAO FRIENDS / LINE FRIENDS-BT21 = PORTFOLIO (platform- or studio-owned); government/public-body-owned mascots = EXCLUDED entirely (the Kumamon rule); a brand's OWN mascot = NOT COUNTED; co-owned/JV = whoever holds control, genuine 50/50 = UNCLEAR.
Carried forward from prior runs and applied here unchanged: **Butterbear = PORTFOLIO** (Malaysia row 8 - corporate-owned mascot of the Butterbear dessert brand under Coffee Beans by Dao; designed by artist Lalalhuay but brand-owned); **CRYBABY, SKULLPANDA, HACIPUPU, Hirono = PORTFOLIO** (POP MART controls the commercialisation, Malaysia row 13); **Monchhichi = PORTFOLIO** (Sekiguchi Co. Ltd, Malaysia row 103); **Teletubbies = PORTFOLIO** (WildBrain estate, Korea row 115); **LuLu the Piggy / Toyzeroplus stable = INDEPENDENT, REP=no** (Taiwan-v2 row 5 - small designer-toy studio, no conglomerate parent, but exclusively channelled).

**Thailand-specific rules:**
- **Thai-native sourcing is mandatory, and source language is flagged.** Thailand's character-collab coverage lives on Thai-language trade press, brand Facebook pages and LINE, not on English media. Every row below rests on a Thai-language source. The `TH-src` flag in Notes marks rows where the campaign detail was read out of Thai body copy; `TH-src (low conf)` marks rows where translation confidence on a specific detail is low and the detail is recorded conservatively rather than guessed. Zero rows are recorded from an English-only source.
- **Sticker-native creator ownership (the indie bucket's hinge):** a Thai creator whose character originated as LINE stickers OWNS that character even though LINE hosts the stickers. Hosting is not owning - the same line the Korea run drew for webtoon platforms. LINE Friends' own characters (Brown, Cony, Sally) remain PORTFOLIO because LINE created and owns them.
- **CP / conglomerate retail concentration:** 7-Eleven Thailand (CP ALL), Lotus's, Big C and CJ MORE run character campaigns at national scale. Each campaign is one row and the brand is recorded as the Thai operator. A regional or global deal is NOT counted into TH unless TH activation is evidenced (TH store presence, TH-market announcement, Thai-social promotion) - the same rule as Malaysia's franchise-local call.
- **Known-entity rule:** Cheesy Duck (X10 Studio) is recorded from PUBLIC sources only, exactly like any other row - no internal knowledge enters the census. Where a public source and internal knowledge disagree, the census records the public source. No Cheesy Duck row has surfaced from a public Thai source in this pass; that is a coverage statement about this pass, not a claim that none exists.

**REPRESENTABLE** (INDEPENDENT rows only) = yes / no / unclear: yes = creator-owned, no conglomerate stake, not locked to an exclusive agency/captive arrangement in a way that precludes representation (a plausible PBC client); no = indie by ownership but already exclusively tied up; unclear = can't tell from public sources. Non-indie rows carry '-'.

**Owed sweeps (this pass is a seed, and the gaps are named rather than papered over):**
1. **The sticker-native indie scene.** Not yet mined. LINE Creators Market top-seller creators, Thai illustrator collab press, and Thai licensing-agency rosters all remain unswept. The 4 indie rows below are almost certainly a large undercount, and no ratio should be quoted off this file until that sweep runs.
2. **Brand Facebook pages.** FB dominates Thai brand comms and the task names it as first-class. This pass used trade press only.
3. **Second and third trade titles.** Marketing Oops, Marketeer, Positioning and MARKETING-INTERACTIVE TH are unswept; only Brand Buffet has been run. Single-vein sourcing is the main structural weakness of this pass.
4. **7-Eleven / Lotus's / Big C campaign calendars.** CP-scale retail is represented by only 2 rows here, which is implausibly thin for this market.
