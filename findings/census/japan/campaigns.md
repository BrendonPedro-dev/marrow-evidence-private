# Japan co-branding census - campaign log

This is a growing, curl-verified table of identifiable brand-x-IP **co-branding** campaigns (コラボ) in the Japan market, 2024-01-01 to run date.
Scope is co-branding only - a brand pairing with a character/illustration/toy IP for products, drinks, food, events, kuji (くじ) or stores.
Excluded: plain licensed merchandise at retail, KOL/celebrity endorsements, and brand-x-brand tie-ins with no character IP.
This is the JAPAN run in a region-by-region series (Taiwan done: 129 rows at `findings/census/campaigns.md`); identical definition and rules so the markets are directly comparable.

**Method (sample census, not exhaustive):** sweep of ja lifestyle/food/fashion press (PR TIMES, Fashion Press, entabe, netlab/nlab ねとらぼ, animatetimes), convenience-store and cafe campaign pages (7-ELEVEN/FamilyMart/Lawson, Starbucks, Mister Donut, McDonald's ハッピーセット), apparel capsule pages (UNIQLO UT, GU, GRANIPH), collab-cafe / pop-up coverage, and licensing trade press.
Every row below was confirmed against at least one fetched source URL; rows resting on a single roundup source are flagged in the Notes column.
Phantom (unverifiable) entries are the known failure class and are kept out.

**YEAR tag** is by campaign start/run date: `2024` = 2024-01-01..2024-12-31, `2025` = 2025-01-01..2025-12-31, `2026YTD` = 2026-01-01..run date.

**IP class** = PORTFOLIO (owned/controlled by a major licensor, studio, media/platform conglomerate, or estate that manages OTHER IP) / INDEPENDENT (living-creator- or small-studio-owned, no conglomerate parent; agency-managed but creator-owned still counts) / UNCLEAR (state why).

**Pinned edge cases (identical to Taiwan run):** Chiikawa (nagano) = PORTFOLIO (publisher/committee-managed); Miffy/Mercis BV = PORTFOLIO (estate); Snoopy/Peanuts = PORTFOLIO (Sony controlling stake); Sanrio / San-X / Pokemon-Nintendo = PORTFOLIO; a brand's OWN mascot = NOT COUNTED; government/public-body-owned (e.g. Kumamon) = EXCLUDED from the split, noted separately; agency-MANAGED but creator-OWNED = INDEPENDENT.

**REPRESENTABLE** (indie rows only) = yes / no / unclear: yes = creator-owned, no conglomerate stake, not locked to an exclusive agency in a way that precludes representation (a plausible PBC client); no = indie by ownership but already exclusively tied up; unclear = can't tell from public sources.
