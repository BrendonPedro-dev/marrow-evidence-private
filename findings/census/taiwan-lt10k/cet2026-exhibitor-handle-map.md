# Creative Expo Taiwan 2026 exhibitor directory - name-to-Instagram-handle map, with follower bands

Build 3 artefact. Swept 2026-08-07 from the public exhibitor directory at `https://creativexpo.tw/zh-TW/exhibitor_list/<id>`, ids 1-749.
`robots.txt` names only SemrushBot, MJ12bot, AhrefsBot and DotBot as disallowed and carries `User-agent: * / Allow: /`.

**Why this file exists.** Builds 1 and 2 both ended blocked on the same thing: no reachable index maps a Chinese-character IP name to an Instagram handle, so 100+ documented DEVILCASE collaborations sat unbanded.
This directory is that index. Each exhibitor detail page is server-rendered and carries the exhibitor's own social links in the page body.

It is **not** a collaboration source - exhibiting at 文博會 is not a brand collaboration - so no row in `rows.md` is sourced from it.
It is used two ways: as a name-to-handle map to unblock other veins, and as a second exactly-denominated Taiwanese creative-sector denominator.

**188 of 402 exhibitors - 46.8% - are sub-10k.**
This is the second exactly-known Taiwanese denominator in this run and the first that is not a licensing roster.
RHINOSHIELD's licensing roster is 13.4% sub-10k; the 文博會 exhibitor floor is 46.8%.
The gap between those two numbers is the licensing filter itself, measured: roughly a third of the sub-10k creative population is present at the trade show and absent from the licensing roster.
The census, built from press, recorded the band at zero.

**Caveat that must travel with the number.** The 402 banded are the exhibitors who publish an Instagram handle on their directory page; the 227 who publish none are unbanded, not counted as anything. If handle-publishing correlates with scale in either direction the 46.8% moves.
