# Singapore co-branding census - campaign log

This is a curl-verified table of identifiable brand-x-IP **co-branding** campaigns in the Singapore market, 2024-01-01 to run date (2026-07-29).
Scope is co-branding only - a brand pairing with a character/illustration/toy IP for products, drinks, food, events, pop-ups or stores.
F&B-led but not F&B-only: retail, convenience, telco, banking, mall, transport and loyalty campaigns count when a character IP fronts a consumer campaign.
Excluded: plain licensed merchandise at retail, KOL/celebrity endorsements, and brand-x-brand tie-ins with no character IP.
**Status at 2026-07-29: 81 curl-verified rows (13x 2024, 43x 2025, 25x 2026YTD).**
This is the SINGAPORE run - market six in a region-by-region series (Taiwan v2: 129 rows at `findings/census/taiwan-v2/campaigns.md`; Japan: 131 rows at `findings/census/japan/campaigns.md`; Korea: 135 rows at `findings/census/korea/campaigns.md`; Malaysia: 103 rows at `findings/census/malaysia/campaigns.md`; Thailand: 83 rows at `findings/census/thailand/campaigns.md`); identical definition and rules so all markets compare row-for-row.

**Method (sample census, not exhaustive).**
Singapore's character-collab coverage is English-dominant and lives on lifestyle/consumer portals rather than on marketing trade press, so the sweep ran against those portals directly.
Five veins are swept, all via each site's own WordPress REST endpoint (`/wp-json/wp/v2/posts?search=...&after=2023-12-01`), which returns the publisher's own machine-readable `date` field alongside the article link: **TheSmartLocal SG** (`thesmartlocal.com`), **Eatbook** (`eatbook.sg`), **Zula** (`zula.sg`), **Geek Culture** (`geekculture.co`) and **Vulcan Post** (`vulcanpost.com`).
SG Magazine (`sgmagazine.com`) was swept and yielded candidates but contributed no surviving row.
Every row below was then confirmed by a second `curl` against the live article URL, returning HTTP 200 with a `datePublished` value in the page's JSON-LD; the Date column is the evidenced campaign window where the body states one, and the publication date otherwise (marked "announced").

**Both keyword classes ran from the start of this market's sweep** - the re-sweep lesson from Taiwan/Japan/Korea/Malaysia/Thailand is baked in here, not retrofitted:
- *Brand-side:* collab, collaboration, character, mascot, blind box, pop-up, limited edition, plushie, merch, licensed, plus entity names (Sanrio, Pop Mart, Labubu, Doraemon, Chiikawa, Snoopy, Duffy, Smiski, Sonny Angel), venue names (Jewel, VivoCity, ION Orchard, Takashimaya, Suntec City) and brand names (Singtel, StarHub, DBS, UOB, OCBC, Shopee, Lazada, EZ-Link, Watsons, Guardian, Cold Storage, NTUC).
- *Artist-side:* illustrator, local artist, Singapore artist, homegrown brand, creator, artist collab, designer toy, art toy, local illustrator, artist.
What the artist-side class returned in Singapore is itself the market's headline finding and is written up in `_VERDICT.md` section 4.

**Sites that could not be swept with `curl`** (recorded as a method limit, not a coverage claim): **Marketing-Interactive** (SG's main marketing trade title) serves a JS-rendered search returning zero article links to `curl` and has no WP REST endpoint; **Mothership** returns HTTP 403 on `/wp-json` and ignores `?s=`, returning the homepage feed; **Straits Times**, **TimeOut Singapore**, **SethLui**, **Daniel Food Diary**, **AugustMan** and **HoneyKids Asia** return 403/404 or JS-only search.
Brand and mall social accounts (Instagram/Facebook), which carry a lot of SG campaign comms, are entirely unswept.

**YEAR tag** is by campaign start/run date: `2024` = 2024-01-01..2024-12-31, `2025` = 2025-01-01..2025-12-31, `2026YTD` = 2026-01-01..run date.
Where a campaign was announced in one year and ran in the next, the year tag follows the run (e.g. KFC x mofusand, announced 2024-12-30, runs from 2025-01-13, is tagged 2025).

**IP class** = PORTFOLIO (owned/controlled by a major licensor, studio, media/platform conglomerate, or estate that manages OTHER IP) / INDEPENDENT (living-creator- or small-studio-owned, no conglomerate parent; agency-managed but creator-owned still counts - the Capoo precedent) / UNCLEAR (state why).

**Pinned edge cases (identical to Taiwan-v2/Japan/Korea/Malaysia/Thailand runs):** Miffy/Mercis BV = PORTFOLIO (estate); Snoopy/Peanuts = PORTFOLIO (Sony controlling stake); Sanrio / San-X / Pokemon-Nintendo / Disney-Marvel-Pixar-Lucasfilm / Warner Bros / Hasbro / Bandai / Sega / Capcom / KAKAO FRIENDS / LINE FRIENDS = PORTFOLIO (platform-, studio- or corporation-owned); government/public-body-owned mascots = EXCLUDED entirely (the Kumamon rule); a brand's OWN mascot = NOT COUNTED; co-owned/JV = whoever holds control, genuine 50/50 = UNCLEAR.
Carried forward and applied unchanged: **mofusand = INDEPENDENT, REP=no** (Japan rows 11/22/85 - created and owned by illustrator ぢゅの, agency-managed by Gray Parka Service, so creator-owned but exclusively channelled); **Butterbear = PORTFOLIO** (Malaysia row 8 / Thailand - corporate-owned mascot of the Butterbear dessert brand under Coffee Beans by Dao; designed by artist Lalalhuay but brand-owned); **Labubu/THE MONSTERS, CRYBABY, SKULLPANDA, HACIPUPU, DIMOO, MOLLY, Mokoko, KUBO, Hirono = PORTFOLIO** (POP MART controls the commercialisation, Taiwan-v2 row 11 / Malaysia row 13); **Monchhichi = PORTFOLIO** (Sekiguchi Co. Ltd, Malaysia row 103); **Bellygom = PORTFOLIO** (Lotte Home Shopping / Lotte Group, Thailand precedent); **wiggle wiggle = PORTFOLIO** (Korean corporate design brand, Thailand rows 1/83).

**Singapore-specific rules:**
- **The regional-HQ trap, and the rule that answers it.** Singapore hosts SEA regional headquarters, so campaigns are routinely *announced from* or *reported in* Singapore that never activate here.
A row requires **evidenced SG activation**: named SG stores/outlets, an SG-market launch date, an SG mall or airport venue, S$ pricing, or .sg commerce.
Announcements without SG activation are rejected and listed in "Rejected rows" below.
This is the Malaysia franchise-local rule, inverted for an HQ market.
- **Mall and loyalty concentration, and the anti-inflation merge.** CapitaLand malls, Jewel/Changi, Suntec, VivoCity, Marina Square, Bugis+ and the CVS/loyalty programmes (7-Eleven SG, FairPrice, Shopee, Grab) run character campaigns at density.
One campaign is one row even when it spans several venues: the CRYBABY "Crying For Love" run across five CapitaLand malls is row 15, venues noted, not five rows; the Disney Dessert Besties run across four Allgreen malls is row 73.
- **Art-toy retail.** The licensor's own retail is NOT a row - POP MART store openings and Pokémon Center Singapore itself are excluded.
A POP MART or Disney Store property **hosted by a third-party venue** IS a row, on the Taiwan-v2 row 126 venue precedent (rows 12, 41, 46, 65, 67).
- **State-adjacent brands.** The Kumamon rule excludes government-*owned mascots* - that is a test on the IP side.
A statutory board or state-linked operator appearing on the *brand* side, licensing a third-party character IP, is a normal row and is flagged in Notes (rows 36 NLB x Star Wars, 75 SimplyGo x Mr. Merlion & Friends).
Singapore's own state-owned mascots (e.g. Singa the Courtesy Lion, SG Clean's mascots) produced no candidate row in this sweep; had one appeared it would have been excluded.
- **A brand's own plushie line is not a character IP row.** Singapore's 2025-26 "food plushie" wave is enormous - MILO, KitKat, Magnolia, Skippy, Tai Sun, Gardenia, Prima Flour, Pizza Hut Cheeseburger Melts, Genki Sushi Squad, McDonald's Prosperity Pals and Pocket Pouch, Toast Box x Horlicks, LiHO's own keychain and strawberry plushies.
All are in-house designs with no third-party character licensor and all are excluded.
This is the single largest rejection class in this market and it is a finding, not an omission.

**REPRESENTABLE** (INDEPENDENT rows only) = yes / no / unclear: yes = creator-owned, no conglomerate stake, not locked to an exclusive agency/captive arrangement in a way that precludes representation (a plausible PBC client); no = indie by ownership but already exclusively tied up; unclear = can't tell from public sources.
Non-indie rows carry '-'.
