# Korea co-branding census - campaign log

This is a growing, curl-verified table of identifiable brand-x-IP **co-branding** campaigns (콜라보 / 컬래버) in the Korea market, 2024-01-01 to run date.
Scope is co-branding only - a brand pairing with a character/illustration/toy IP for products, drinks, food, events, pop-ups or stores.
Excluded: plain licensed merchandise at retail, KOL/celebrity endorsements, and brand-x-brand tie-ins with no character IP.
This is the KOREA run in a region-by-region series (Taiwan done: 129 rows at `findings/census/campaigns.md`; Japan done: 131 rows at `findings/census/japan/campaigns.md`); identical definition and rules so the three markets are directly comparable.

**Method (sample census, not exhaustive):** sweep of ko lifestyle/food/fashion/brand press (Naver news, 매일경제/한국경제 lifestyle, 데일리팝, 인사이트, 위키트리, 뉴스핌, 브랜드브리프), convenience-store and cafe collab coverage (CU/GS25/세븐일레븐/이마트24 campaign pages, 메가커피/컴포즈커피/투썸/스타벅스 collab coverage), brand official announcements/press releases, character-goods and pop-up (더현대 서울/성수 팝업) coverage, and licensing trade press.
Every row below was confirmed against at least one fetched source URL; rows resting on a single roundup source are flagged in the Notes column.
Phantom (unverifiable) entries are the known failure class and are kept out.

**YEAR tag** is by campaign start/run date: `2024` = 2024-01-01..2024-12-31, `2025` = 2025-01-01..2025-12-31, `2026YTD` = 2026-01-01..run date.

**IP class** = PORTFOLIO (owned/controlled by a major licensor, studio, media/platform conglomerate, or estate that manages OTHER IP) / INDEPENDENT (living-creator- or small-studio-owned, no conglomerate parent; agency-managed but creator-owned still counts) / UNCLEAR (state why).

**Pinned edge cases (identical to Taiwan/Japan runs):** Kakao Friends / 카카오프렌즈 (Ryan, Apeach, etc.) = PORTFOLIO (Kakao platform-owned); LINE Friends / 라인프렌즈 (BT21 included - platform-owned IP even with BTS creative input) = PORTFOLIO; Pinkfong/Baby Shark (더핑크퐁컴퍼니) = PORTFOLIO (media company, multi-IP); Sanrio / San-X / Pokemon-Nintendo / Disney = PORTFOLIO; Miffy/Mercis BV = PORTFOLIO (estate); Snoopy/Peanuts = PORTFOLIO (Sony controlling stake); a brand's OWN mascot = NOT COUNTED; government/public-body-owned = EXCLUDED from the split, noted separately. **KEY KOREA DISTINCTION:** webtoon/sticker characters = INDEPENDENT only if the artist retains ownership (agency-managed but creator-owned still counts); PORTFOLIO if the platform (Kakao/LINE/Naver) owns the character.

**REPRESENTABLE** (indie rows only) = yes / no / unclear: yes = creator-owned, no conglomerate stake, not locked to an exclusive agency in a way that precludes representation (a plausible PBC client); no = indie by ownership but already exclusively tied up; unclear = can't tell from public sources.
